# Руководство по управлению компаниями и счетами

## Обзор

Администраторы и менеджеры факторинговой компании теперь могут создавать новые компании и счета через веб-интерфейс.

## Доступ к функциям

### Права доступа

**Требуется роль:** `ROLE_ADMIN`

Только администраторы могут:
- Создавать новые компании
- Редактировать информацию о компаниях
- Активировать/деактивировать компании
- Создавать счета для компаний
- Управлять балансами счетов

### Вход в систему

1. Откройте http://localhost:8080/admin-companies.html
2. Войдите под учетной записью администратора
3. Вы увидите список всех компаний в системе

## Создание компании

### Через веб-интерфейс

1. Нажмите кнопку **"Создать компанию"** в правом верхнем углу
2. Заполните форму:
   - **Название компании** (обязательно) - например, "ООО Новая Компания"
   - **Тип** (обязательно):
     - `supplier` - Поставщик
     - `debtor` - Дебитор
     - `factor` - Фактор
   - **ИНН** (обязательно) - 10 или 12 цифр
   - **КПП** (опционально) - 9 цифр
   - **ОГРН** (опционально) - 13 цифр
   - **Юридический адрес**
   - **Почтовый адрес**
   - **Расчетный счет** - 20 цифр
   - **БИК банка** - 9 цифр
   - **Корреспондентский счет** - 20 цифр

3. Нажмите **"Создать компанию"**

### Через API

```bash
# Получить токен администратора
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@finansfactor.ru","password":"YOUR_PASSWORD"}' \
  | grep -o '"token":"[^"]*' | cut -d'"' -f4)

# Создать компанию
curl -X POST http://localhost:8080/api/companies \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "ООО Тестовая Компания",
    "inn": "7701234567",
    "kpp": "770101001",
    "ogrn": "1027700123456",
    "type": "supplier",
    "legalAddress": "г. Москва, ул. Ленина, д. 10",
    "postalAddress": "г. Москва, ул. Ленина, д. 10",
    "bankAccount": "40702810100000012345",
    "bankBik": "044525225",
    "correspondentAccount": "30101810400000000225"
  }'
```

## Создание счета для компании

### Предварительные требования

1. Компания должна существовать
2. У компании должен быть хотя бы один пользователь (владелец счета)

### Через веб-интерфейс

1. В списке компаний найдите нужную компанию
2. Нажмите кнопку **"+ Счет"**
3. Выберите владельца из списка пользователей компании
4. Заполните:
   - **Название счета** - например, "Операционный счет"
   - **Начальный баланс** - например, 100000
   - **Валюта** - RUB, USD или EUR

5. Нажмите **"Создать счет"**

### Через API

```bash
# Сначала получить ID компании и ID пользователя
COMPANY_ID="uuid-компании"
USER_ID="uuid-пользователя-владельца"

# Создать счет
curl -X POST http://localhost:8080/api/accounts \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Операционный счет",
    "companyId": "'$COMPANY_ID'",
    "ownerId": "'$USER_ID'",
    "balance": 100000,
    "currency": "RUB"
  }'
```

## Просмотр счетов компании

### Через веб-интерфейс

1. Нажмите кнопку **"👁 Счета"** на карточке компании
2. Появится список всех счетов компании с балансами

### Через API

```bash
# Получить все счета компании
curl -X GET "http://localhost:8080/api/accounts?companyId=$COMPANY_ID" \
  -H "Authorization: Bearer $TOKEN"

# Получить конкретный счет
curl -X GET "http://localhost:8080/api/accounts/$ACCOUNT_ID" \
  -H "Authorization: Bearer $TOKEN"
```

## Управление компаниями

### Фильтрация по типу

В интерфейсе доступны вкладки:
- **Все компании** - показать все
- **Поставщики** - только supplier
- **Дебиторы** - только debtor
- **Факторы** - только factor

### Деактивация компании

```bash
curl -X POST "http://localhost:8080/api/companies/$COMPANY_ID/deactivate" \
  -H "Authorization: Bearer $TOKEN"
```

### Активация компании

```bash
curl -X POST "http://localhost:8080/api/companies/$COMPANY_ID/activate" \
  -H "Authorization: Bearer $TOKEN"
```

### Редактирование компании

```bash
curl -X PUT "http://localhost:8080/api/companies/$COMPANY_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "ООО Новое Название",
    "legalAddress": "Новый адрес"
  }'
```

## Управление счетами

### Изменение баланса (административная корректировка)

```bash
curl -X PUT "http://localhost:8080/api/accounts/$ACCOUNT_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "balance": 250000
  }'
```

### Удаление счета

**Внимание:** Счет можно удалить только если баланс = 0

```bash
curl -X DELETE "http://localhost:8080/api/accounts/$ACCOUNT_ID" \
  -H "Authorization: Bearer $TOKEN"
```

## API Endpoints

### Companies

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/companies` | Список всех компаний |
| GET | `/api/companies?type=supplier` | Фильтр по типу |
| GET | `/api/companies?status=active` | Фильтр по статусу |
| GET | `/api/companies/{id}` | Информация о компании |
| POST | `/api/companies` | Создать компанию |
| PUT | `/api/companies/{id}` | Обновить компанию |
| POST | `/api/companies/{id}/activate` | Активировать |
| POST | `/api/companies/{id}/deactivate` | Деактивировать |

### Accounts

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/accounts` | Список всех счетов |
| GET | `/api/accounts?companyId=xxx` | Счета компании |
| GET | `/api/accounts/{id}` | Информация о счете |
| POST | `/api/accounts` | Создать счет |
| PUT | `/api/accounts/{id}` | Обновить баланс |
| DELETE | `/api/accounts/{id}` | Удалить счет (баланс 0) |

### Users (для получения владельцев)

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/admin/users` | Все пользователи |
| GET | `/api/admin/users?companyId=xxx` | Пользователи компании |

## Типовые сценарии

### Сценарий 1: Новый поставщик

1. Создать компанию типа `supplier`
2. Зарегистрировать пользователя (менеджера поставщика) через `/api/auth/register` с `companyId`
3. Создать операционный счет для компании
4. Пополнить баланс счета
5. Поставщик может начать работу

### Сценарий 2: Новый дебитор

1. Создать компанию типа `debtor`
2. Зарегистрировать финансового менеджера дебитора
3. Создать расчетный счет
4. Настроить лимиты (если требуется)
5. Дебитор может принимать поставки

### Сценарий 3: Тестовая среда

1. Создать несколько тестовых компаний всех типов
2. Для каждой создать по 2-3 счета с разными балансами
3. Зарегистрировать тестовых пользователей
4. Выполнить тестовые переводы между счетами
5. Проверить аудит-логи

## Безопасность

- Все endpoints требуют `ROLE_ADMIN`
- JWT токен обязателен для всех запросов
- Валидация всех входных данных
- Проверка уникальности ИНН при создании компании
- Владелец счета должен принадлежать указанной компании
- Невозможно удалить счет с балансом > 0

## Ограничения текущей реализации

1. **Account entity не имеет setter для name** - имя счета задается при создании и не может быть изменено
2. **Нет типов счетов** - все счета универсальные (можно добавить enum: операционный, резервный, комиссионный и т.д.)
3. **Нет проверки банковских реквизитов** - можно ввести невалидные БИК или номера счетов
4. **Нет мягкого удаления** - компании и счета удаляются физически (можно добавить soft delete)

## Поддержка

Если возникли проблемы:

1. Проверьте роль пользователя (`ROLE_ADMIN` обязательна)
2. Проверьте валидность JWT токена
3. Убедитесь, что компания существует перед созданием счета
4. Проверьте, что у компании есть пользователи для назначения владельцем счета
5. Проверьте логи: `docker compose logs php | tail -100`
